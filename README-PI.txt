LAUDI ON A RASPBERRY PI

1. Copy this laudi folder onto the Pi (e.g. /home/<you>/laudi).
2. From the PC's Desktop\tiktok-bot folder, copy local-settings.txt (and .env if there is one) into it too.
3. On the Pi open a Terminal in the folder and run:   bash install-laudi.sh
4. On the PC: Laudi Control > Stop, then double-click retire-pc-laudi.bat (copy it to the PC's tiktok-bot folder first).
5. In the Chromium window that opens on the Pi, log Laudi in again: TikTok, Element, WhatsApp (QR), Gmail, Instagram, Edunation.

Phone remote: http://<pi-ip>:8787 (the installer shows the link + PIN).
Away from home: DM Laudi !status !restart !log !update on Discord/Element.
Not on the Pi: playing Roblox + clips (Roblox doesn't run on a Pi).
